# Demonstration imagery provenance

- `phailin-01-formation.png` through `phailin-04-decaying.png` are crops from
  the repository's committed `data/processed/phailin_lifecycle.png` contact
  sheet, which was created from HURSAT-B1/Meteosat-7 imagery.
- `insat3d-demo-sample.jpg` is the sample `30.jpg` distributed by the public
  CycloNet demonstration repository at
  `Sparshj8287/Cyclonet`. That project identifies the selected CC0 Kaggle
  INSAT-3D dataset as its curated dataset source. The file is included solely
  to exercise the legacy model's expected image convention and is not used as
  accuracy evidence.

Every image is historical and non-operational. Embedded or filename intensity
labels are source metadata, not Cyclone-AI predictions.
